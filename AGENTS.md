# Repository instructions

- This is a Java 27 Spring Boot application built with Maven.
- Use the Maven Wrapper for builds and tests: `mvnw.cmd` on Windows or `./mvnw` on Unix-like systems.
- Follow the existing Spring Boot conventions and keep changes focused.
- Add or update tests for behavior changes, and run `mvnw.cmd test` before submitting.
- If OpenAPI generation is added, treat the OpenAPI specification as the source of truth; do not edit generated code by hand.
